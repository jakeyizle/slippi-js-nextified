# `slippi-js-nextified`

This is a super hacky fork of slippi-js that works in Next-js without any polyfills (I think). It is intended more as a jumping off point for others to adapt than for real use.
I removed some stuff relating to console/dolphin connections which I think is related to real-time reading / mirroring?
I did not update any tests, and skipped a lot of TS warnings.

Do not pass a string into SlippiGame.
